# Processed climate data

`abu_dhabi_tmy_processed.csv` is generated by `python -m carnot.cli all` (experiment E1) from
`data/raw/pvgis_tmy_abu_dhabi.csv`. It is committed so figures and tests can run without
re-downloading.

Source: **PVGIS v5.3**, Typical Meteorological Year for 24.454 N, 54.377 E, elevation 5 m
(SARAH-3 satellite irradiance + ERA5 meteorology, 2005–2023).

## Processing steps

1. **Index rebuild.** PVGIS concatenates twelve typical months taken from different years, so the
   raw timestamps jump at month boundaries (a few "days" contain 4 or 20 hours). The values form a
   continuous 8 760-hour year, so the index is rebuilt on a synthetic calendar year
   (2001-01-01 00:00 UTC, then shifted to Gulf Standard Time, UTC+4). Only month/day/hour are
   meaningful; the year is not.
2. **Clipping.** Negative irradiance is set to zero; wind speed floored at 0.3 m/s.
3. **Solar geometry.** NOAA solar position (zenith, azimuth) at each hour.
4. **Plane-of-array.** Cabinet irradiance is 30 % roof (horizontal GHI) plus 70 % average of four
   vertical facades with isotropic sky and 0.2 ground albedo.
5. **Sky temperature.** The PVGIS `IR(h)` column in this product is unusable (mostly 0 W/m² with
   isolated ~430 W/m² spikes, physically impossible for downward longwave). Sky temperature is
   instead derived from air temperature and dew point with the Berdahl & Martin (1984) clear-sky
   emissivity.

## Columns

`t_amb_c`, `rh_pct`, `ghi`, `dni`, `dhi`, `wind_ms`, `zenith_deg`, `azimuth_deg`,
`ghi_cabinet`, `t_sky_c`.
